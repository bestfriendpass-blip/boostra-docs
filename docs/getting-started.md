# Быстрый старт

Эта страница — краткая инструкция по работе с порталом документации локально.

## Запуск локального сервера

```bash
# Запустить предпросмотр с автоперезагрузкой
mkdocs serve
```

После запуска откройте в браузере <http://127.0.0.1:8000>. Любые изменения в `.md` файлах подхватываются автоматически.

!!! note "Сборка статики"
    Чтобы собрать готовый сайт в папку `site/`, выполните `mkdocs build`.

## Добавление новой страницы

1. Создайте файл, например `docs/moy-razdel/statya.md`.
2. Пропишите его в `nav` в файле `mkdocs.yml`:

    ```yaml
    nav:
      - Мой раздел:
          - Статья: moy-razdel/statya.md
    ```
